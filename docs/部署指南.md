# 阿里云部署指南

## 架构总览

```
参赛者浏览器
   │ HTTPS (443)
   ▼
┌──────────┐  反向代理   ┌──────────────┐
│  Nginx   │ ──────────▶ │  Flask :8080 │  ← oj-server.service
│  443/80  │             └──────────────┘
└──────────┘                    │
                                │ SQLite (WAL)
                                ▼
                        ┌──────────────┐
                        │  评测 worker  │  ← oj-worker.service
                        │  (子进程隔离) │
                        └──────────────┘
```

两个 systemd 服务跑在低权限用户 `oj` 下；Nginx 负责 TLS 终止与反代。

---

## 准备工作

### 购买云服务器（ECS）

推荐规格：
- 1 核 2GB 或 2 核 2GB（突发型 t5/t6 即可，月费约 30-60 元）
- 系统镜像：Ubuntu 22.04 LTS
- 安全组开放端口：**22**（SSH）、**80**、**443**

> 注意：对外只暴露 80/443，**不要开放 8080**，Flask 只监听本机回环。

### 域名 DNS

在域名服务商处添加 A 记录：

```
hackathon.turing-zero.com  →  <你的公网IP>
```

## 二、一键部署（推荐）

项目内 `deploy/` 目录已包含完整的 systemd + nginx 配置，推荐用 `setup.sh` 一键部署：

```bash
# 1. 拉取项目
cd /home
git clone https://github.com/Mark-tz/hackathon.git
cd hackathon

# 2. 运行部署脚本（创建 oj 用户、装依赖、注册 systemd 服务）
sudo bash deploy/setup.sh

# 3. 编辑环境变量文件，设置管理员密钥
sudo nano /etc/oj.env
#   → 把 OJ_ADMIN 改成随机字符串，如 OJ_ADMIN=$(openssl rand -hex 24)

# 4. 启动服务
sudo systemctl start oj-server oj-worker
```

脚本做了什么：
- 安装 `python3 python3-pip git flask`
- 创建系统用户 `oj`（无家目录、无登录 shell），供服务运行
- 把 `oj/uploads`、`oj/viz`、`oj/oj.db` 归属 `oj:oj`，代码目录保持 root 只读
- 拷贝 `oj.env.example` → `/etc/oj.env`（权限 640，root:oj）
- 注册 `oj-server.service` / `oj-worker.service` 并 `enable`
- 以 `oj` 用户初始化数据库

## 三、配置 Nginx 反向代理 + HTTPS

### 3.1 安装 Nginx 和 certbot

```bash
sudo apt-get install -y nginx certbot python3-certbot-nginx
```

### 3.2 部署站点配置

```bash
sudo cp deploy/nginx-hackathon.conf /etc/nginx/sites-available/hackathon
sudo ln -sf /etc/nginx/sites-available/hackathon /etc/nginx/sites-enabled/hackathon
# 移除默认站点避免冲突
sudo rm -f /etc/nginx/sites-enabled/default
```

### 3.3 先用 HTTP 配置测试连通

在签证书之前，先临时改用纯 HTTP 配置验证 Flask 能通：

```bash
# 临时注释掉 HTTPS server 块，只保留 HTTP 块并把 location / 改为 proxy_pass
sudo nginx -t && sudo systemctl reload nginx
curl -I http://hackathon.turing-zero.com/
# 期望 200 或 301/302
```

### 3.4 申请 Let's Encrypt 证书

```bash
sudo mkdir -p /var/www/certbot
sudo certbot --nginx -d hackathon.turing-zero.com \
    --non-interactive --agree-tos -m you@example.com --redirect
```

certbot 会自动改写 nginx 配置注入证书路径；若你的 `nginx-hackathon.conf` 已预留了 `ssl_certificate` 行，certbot 可直接复用。申请完确认：

```bash
sudo nginx -t && sudo systemctl reload nginx
```

### 3.5 验证 HTTPS

```bash
curl -I https://hackathon.turing-zero.com/
```

浏览器访问 `https://hackathon.turing-zero.com` 即可看到 OJ 前端页面。

## 四、日常运维命令

```bash
# 查看服务状态
sudo systemctl status oj-server oj-worker

# 实时日志
sudo journalctl -u oj-server -f
sudo journalctl -u oj-worker -f

# 重启服务
sudo systemctl restart oj-server oj-worker

# 阶段切换（A → B）
sudo sed -i 's/^OJ_PHASE=.*/OJ_PHASE=B/' /etc/oj.env
sudo systemctl restart oj-server

# 批量添加队伍
sudo -u oj python3 /home/hackathon/oj/db.py addteam "队伍名称"

# 备份数据库
sudo cp /home/hackathon/oj/oj.db /home/hackerson/oj/oj.db.bak
```

## 五、安全清单

| 项 | 状态 | 说明 |
|----|------|------|
| Flask 只监听 127.0.0.1 | ✅ | nginx 反代，不直接暴露 8080 |
| 低权限用户 `oj` | ✅ | 服务以系统用户身份运行，无登录 shell |
| systemd 沙箱 | ✅ | `ProtectSystem=strict` `ProtectHome` `PrivateTmp` `NoNewPrivileges` |
| 评测子进程隔离 | ✅ | `RLIMIT_CPU/AS/FSIZE/NOFILE` + 敏感环境变量清除 |
| HTTPS 强制跳转 | ✅ | nginx 80 → 443 301 |
| 管理密钥 | ⚠️ 手动 | `/etc/oj.env` 的 `OJ_ADMIN` 必须改成随机串 |
| 安全组 | ⚠️ 手动 | 阿里云控制台只放行 22/80/443，关闭 8080 |

管理员密钥生成示例：

```bash
openssl rand -hex 24
# 输出例：a3f1b9c8d7e6...（48 字符）
```

## 六、资源估算

| 项目 | 实测值 |
|------|--------|
| 单次评测 wall time | ~0.03s（全部 baseline + 9 个实例） |
| 峰值内存（单次评测子进程） | ~20MB |
| Flask + SQLite 空载 | ~15MB |
| Nginx 空载 | ~5MB |
| 50 队同时涌入（限流 5 分钟/次）| 队列约 5 分钟清空 |

**1 核 2GB 完全够用**，主要瓶颈是磁盘写 viz HTML（22KB/次），可以忽略。

## 附：手动部署（不用 setup.sh）

若想逐步控制：

```bash
# 1. 装依赖
apt update && apt install -y python3 python3-pip git nginx
pip3 install flask

# 2. 建低权限用户
useradd -r -s /sbin/nologin -d /nonexistent -M oj

# 3. 拉代码
cd /home
git clone https://github.com/Mark-tz/hackathon.git

# 4. 初始化数据库
cd /home/hackathon
mkdir -p oj/uploads oj/viz
python3 oj/db.py init
chown -R oj:oj oj/uploads oj/viz oj/oj.db
chmod 660 oj/oj.db

# 5. 配环境变量
cp deploy/oj.env.example /etc/oj.env
chown root:oj /etc/oj.env && chmod 640 /etc/oj.env
# 编辑 OJ_ADMIN...

# 6. 装 systemd 服务
cp deploy/oj-server.service deploy/oj-worker.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable oj-server oj-worker
systemctl start oj-server oj-worker

# 7. 装 nginx（同上 §三）
```

## 故障排查

**服务起不来：**
```bash
sudo journalctl -u oj-server -n 50 --no-pager
```
常见原因：`/etc/oj.env` 权限不对（应为 root:oj 640）、`oj` 用户无法读 `/home/hackathon`。

**评测卡住/超时：**
```bash
sudo journalctl -u oj-worker -n 50 --no-pager
```
看是否有 "评测超时" 或 "OOM killer" 日志。

**nginx 502：**
Flask 没起来或端口不对，检查 `systemctl status oj-server`，确认监听 8080。

**证书续期：**
certbot 会自动装 timer，手动测试：
```bash
sudo certbot renew --dry-run
```
