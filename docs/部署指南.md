# 阿里云部署指南

## 准备工作

### 购买云服务器（ECS）

推荐规格：
- 1 核 2GB 或 2 核 2GB（突发型 t5/t6 即可，月费约 30-60 元）
- 系统镜像：Ubuntu 22.04 LTS
- 安全组开放端口：**22**（SSH）、**8080**（OJ）

---

## 一、连接服务器

```bash
ssh root@<你的公网IP>
```

---

## 二、安装依赖

```bash
apt update && apt install -y python3 python3-pip git screen
pip3 install flask
```

---

## 三、拉取项目

```bash
cd /home
git clone git@github.com:Mark-tz/hackathon.git
cd hackathon
```

如果服务器没有 SSH key，改用 HTTPS：

```bash
git clone https://github.com/Mark-tz/hackathon.git
```

---

## 四、初始化数据库

```bash
cd /home/hackathon
python3 oj/db.py init
```

---

## 五、批量添加队伍

每支队伍运行一次，**token 只显示一次**，记下来分发给各队：

```bash
python3 oj/db.py addteam "队伍名称"
```

或允许参赛者现场自助注册（打开浏览器访问 `/` 页面即可）。

---

## 六、启动 OJ（用 screen 保持后台运行）

**终端 1 — HTTP 服务器：**

```bash
screen -S server
cd /home/hackathon
OJ_PORT=8080 OJ_ADMIN=你设的管理密钥 python3 oj/server.py
# Ctrl+A D 分离 screen
```

**终端 2 — 评测 worker：**

```bash
screen -S worker
cd /home/hackathon
OJ_DB=/home/hackathon/oj/oj.db python3 oj/worker.py
# Ctrl+A D 分离 screen
```

回到后台进程：`screen -r server` / `screen -r worker`

---

## 七、开放安全组端口

在阿里云控制台：
**云服务器 ECS → 实例 → 安全组 → 配置规则 → 添加入方向规则**

| 协议 | 端口 | 授权对象 |
|------|------|----------|
| TCP  | 8080 | 0.0.0.0/0 |

---

## 八、访问

参赛者浏览器打开：

```
http://<公网IP>:8080
```

榜单自动刷新，注册/提交/查看结果均在同一页面。

---

## 阶段切换（B 阶段）

重启 server 时加环境变量：

```bash
OJ_PORT=8080 OJ_ADMIN=密钥 OJ_PHASE=B python3 oj/server.py
```

---

## 安全建议（现场部署）

1. **worker 以低权限用户运行**，防止提交代码写入系统文件：

```bash
useradd -m -s /bin/bash ojworker
chown -R ojworker:ojworker /home/hackathon/oj/uploads /home/hackathon/oj/viz /home/hackathon/oj/oj.db
su - ojworker -c "cd /home/hackathon && OJ_DB=/home/hackathon/oj/oj.db python3 oj/worker.py"
```

2. **设置强管理密钥**：`OJ_ADMIN=` 后面用随机字符串，不要用默认值。

3. **定期备份数据库**：

```bash
cp /home/hackathon/oj/oj.db /home/hackathon/oj/oj.db.bak
```

## 资源估算

| 项目 | 实测值 |
|------|--------|
| 单次评测 wall time | ~0.03s（全部 baseline + 9 个实例） |
| 峰值内存（单次评测子进程） | ~20MB |
| Flask + SQLite 空载 | ~15MB |
| 50 队同时涌入（限流 5 分钟/次）| 队列约 5 分钟清空 |

**1 核 2GB 完全够用**，主要瓶颈是磁盘写 viz HTML（22KB/次），可以忽略。
